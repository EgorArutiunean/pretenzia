# court_orders

Модуль отвечает за генерацию заявлений о вынесении судебного приказа из того же `registry.xlsx`, который используется модулем `claims`.

Источники данных:

- `registry.xlsx` с колонками `Лицевой счет`, `ФИО`, `Адрес`, `Период задолженности`, `Сумма долга`;
- Excel-агрегатор для судебных заявлений `storage/court_orders_static_data.xlsx`.

Связка с агрегатором выполняется по первым 4 цифрам лицевого счета.

Текущие обязательные колонки агрегатора:

- `Номер объекта`;
- `Адрес`;
- `Компания`.

Поддерживаемые дополнительные колонки:

- `Реквизиты`;
- `Протокол`;
- `Ставка`;
- `Подсудность`;
- `Адрес суда`.

Агрегатор можно расширять новыми колонками без изменения формата `registry.xlsx`.
