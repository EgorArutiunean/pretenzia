# court_orders

Модуль отвечает за генерацию заявлений о вынесении судебного приказа из того же `registry.xlsx`, который используется модулем `claims`.

Источники данных:

- `registry.xlsx` с колонками `Лицевой счет`, `ФИО`, `Адрес`, `Период задолженности`, `Сумма долга`;
- основная БЗ `storage/court_orders/base_data.xlsx`;
- БЗ подсудности `storage/court_orders/jurisdiction.xlsx`.

Связка реестра и двух справочников выполняется по первым 4 цифрам лицевого счета.

Обязательные колонки основной БЗ:

- `Номер объекта`;
- `Адрес`;
- `Компания`.
- `Реквизиты`.

Дополнительные колонки основной БЗ:

- `Протокол`;
- `Ставка`;

Обязательные колонки БЗ подсудности:

- `Номер объекта`;
- `Подсудность`;

Дополнительная колонка БЗ подсудности:

- `Адрес суда`.

Если строка реестра не может быть обработана, в итоговый ZIP добавляется `errors.xlsx`. Необязательные данные должника можно передать дополнительными колонками реестра: `Дата рождения`, `Место рождения`, `Адрес регистрации`, `Паспорт` или `Идентификатор должника`.
